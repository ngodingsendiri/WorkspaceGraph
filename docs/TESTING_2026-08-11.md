## Metodologi

1. `npm run dev` + `--remoteDebuggingPort 9222` → jendela Electron asli terbuka di desktop.
2. Driver CDP (`.freebuff/cdp-drive.mjs`) mengevaluasi JS di renderer **asli** (preload
   `window.api` sungguhan, 107 method) → buka vault uji, klik UI, ukur, baca DOM.
3. Screenshot jendela asli via CDP → dilihat lewat vite `@fs` di Preview tab.
4. Kolektor error (`window.__errs`) dipasang sejak awal sesi → **0 error** runtime.

**Catatan jujur:** dialog folder OS tidak bisa dikendalikan dari CDP, jadi vault dibuka
via `window.api.openWorkspace` (alur setelahnya sama dengan klik UI). Chat AI tidak bisa
dites alur sukses karena belum ada API key — yang dites adalah alur error (berfungsi baik).

## Temuan Fungsi (bug nyata)

### 🔴 F-1 · Template ikut diindeks sebagai note → semua statistik & graph tercemar
Saat vault dibuka, app **men-seed 8 file template** ke `Templates/`, dan file itu
**diproses pipeline indeks seperti note biasa**:

| Metrik | Harusnya | Terukur (nyata) |
|--------|----------|-----------------|
| CATATAN (dashboard) | 7 | **15** |
| PROYEK | 2 | **3** (+ `Templates/Project.md`) |
| ORANG | 2 | **3** (+ `Templates/Person.md`) |
| CHECKLIST terbuka | 3 | **8** (template berisi `- [ ]` placeholder) |
| Recent notes ("TERBARU") | note asli | **5× `{{title}}`** (template paling baru) |
| Node graph | 15 | **26** (8 template + ghost) |
| Hasil search | note asli | muncul `{{title}}` (template) |

Bukti: `getGraphData` byType → `template: 8`; `getRecentNotes` → 5× `{{title}}`;
dashboard DOM: CATATAN 15 / PROYEK 3 / ORANG 3 / CHECKLIST 8.
**Rekomendasi:** exclude `Templates/` dari indeks note (atau tandai `isTemplate` dan
saring di semua agregasi), baik di engine maupun di renderer.

> ✅ **DIPERBAIKI 2026-08-11** — helper `isTemplateDir()` (top-level `Templates/` saja)

> recent 6×`{{title}}`→note asli, sqlite 15→7, search 0 hit template.

### 🟠 F-4 · `createFromTemplate` menghilangkan frontmatter → ✅ DIVERIFIKASI
**Hasil audit ulang (2026-08-11): temuan ini tidak ter-reproduksi pada kode saat
ini** — `createFromTemplate` menghasilkan file **dengan frontmatter lengkap**
(`---\ntitle: …\ntype: …\nstatus: …\ncreated: …\n---`) untuk **semua 8 template
builtin** (terverifikasi di aplikasi asli: create → read → rawContent diawali
`---`, key frontmatter terisi). Kemungkinan temuan awal memeriksa field hasil
parse `.content` (body tanpa frontmatter) alih-alih `rawContent` (isi file asli).

Agar invarian ini tidak bisa regresi diam-diam:
- **Struktural:** handler `template:createNote` kini memakai `renderById` —
  fungsi yang SAMA dengan preview `template:render` (sebelumnya `render(tpl.body)`
  manual). Preview dan create dijamin satu source of truth.
- **Regresi test:** `TemplateEngine.test.ts` — tiap builtin render dengan blok
  frontmatter utuh (`---` di awal, `type:` + `created:`/`date:`), dan komposisi
  create-note (vars title/filename/workspace) tidak meninggalkan placeholder.

### 🟠 F-5 · Hitungan link inkonsisten → ✅ SELESAI
Kartu stat dashboard vs header graph view pakai dua jalur hitung berbeda:
dashboard menghitung note asli + edge non-tag, header menghitung **semua node
render sebagai "notes"** (saat tags tampil: 15 = 7 note + 8 tag) dan link dari
sim. Akar masalah: tidak ada satu sumber kebenaran untuk angka "notes · links".

**Fix (2026-08-11):** helper bersama `countGraphNotes`/`countGraphLinks`/
`graphCounts` di `graphViewData.ts` — dashboard card DAN header graph (toolbar
+ HUD overlay) sama-sama memakainya. Semantik: notes = node non-tag/
non-ghost/non-attachment; links = edge non-tag. `stats` mentah tetap dipakai
untuk LOD/perf (bukan tampilan).

**Terverifikasi di aplikasi asli** (CDP, showTags ON): 14 circle + label tag
ter-render, toolbar tetap `7 notes · 11 links` (sebelum fix: `15 notes · 11
links`) — identik dengan kartu dashboard `GRAPH 7/11`. Unit test: 15 node
(7 note + 8 tag) + 13 edge (11 wiki + 2 tag) → `{notes: 7, links: 11}`.

## Temuan Performa

### 🟠 P-1 · Navigasi ke Editor & Graph lambat (~1,0–1,2 dtk), setiap kali → ✅ SELESAI
Diukur di aplikasi asli (vault kecil 15 file). Pola yang ditemukan: navigasi ke
Editor **dan** Graph selalu ~1 dtk, dan memburuk drastis saat **split view aktif**
(934–964 ms) karena setiap navigasi me-remount editor + graph sekaligus.

| Navigasi | Sebelum (ms) | Sesudah (ms) |
|----------|--------------|--------------|
| → Dashboard | 32–108 | 83–115 |
| → Editor (split OFF) | ~1200 | 78–116 |
| → Graph (split OFF) | ~1100 | 136–326 |
| → Graph (split ON, worst) | 934 | 200–201 |
| → Editor (split ON, worst) | 964 | 140–144 |

**Fix (keep-alive):** semua view utama (dashboard/editor/graph/settings) tetap
ter-mount dan hanya di-toggle `hidden` (`ViewKeepAlive` di `AppShell`) — navigasi
menjadi toggle display, bukan remount. MarkdownEditor juga distabilkan posisinya
di dalam struktur `split-view` (variant `--solo`) sehingga toggle split tidak
me-remount editor. Guard pipeline embedded graph dirapikan (hanya jalan saat
split terlihat). State yang tersimpan: undo history, scroll, camera graph.
Terverifikasi di aplikasi asli: view aktif 1, sisanya hidden, graph tetap
melukis 7 node + 11 link, isi editor utuh setelah navigasi pergi-pulang.

### 🟡 P-2 · Search pertama bisa kosong (race indeks)
`searchQuery('alpha')` langsung setelah buka vault → 0 hasil (indeks SQLite belum
dibangun / worker Fuse belum siap); setelah beberapa detik → hasil muncul (lewat UI
modal search: Alpha, Ana, Index, Home). Tidak fatal, tapi user bisa lihat hasil kosong
sebelum indeks siap — pertimbangkan state "mengindeks…" pada hasil search juga
(dashboard sudah menampilkan progress embedding).

## Temuan UI/UX (terhadap parameter user)

### 🟠 A-1 · Animasi belum "empuk & elastis" — terlalu cepat & kaku → ✅ SELESAI
Token animasi lama (`tokens.css`): `--duration-fast: 100ms`, `--duration-normal: 200ms`,
ease datar Material `cubic-bezier(0.4, 0, 0.2, 1)` tanpa overshoot → terasa
keras/instan. **Fix (2026-08-11):**
- **Token baru:** `--duration-fast: 120ms` (micro-interaction tetap responsif),
  `--duration-normal: 250ms`, `--duration-slow: 350ms`; `--ease-soft`
  `cubic-bezier(0.22, 1, 0.36, 1)` (landing panel/slide tanpa overshoot),
  `--ease-spring` `cubic-bezier(0.34, 1.56, 0.64, 1)` (pop elastis; menggantikan
  `--ease-bounce`).
- **Diterapkan selektif** (bukan blanket — hover micro-interaction tetap 120ms):
  modal/search/cmd/dialog/merge → `scaleIn` 350ms + spring + `transform-origin`;
  overlay scrim 250ms; kartu dashboard (`dash-metric`) lift hover 250ms + spring;
  `welcome-action-card` transform → spring; `provider-card` + lift/shadow hover;
  chat panel slide-in → `--ease-soft`; context/format menu pop spring 250ms;
  toast slide-in → spring.
- **Node graph:** entry animation kini `easeOutBack` (overshoot ~1.09 → pop
  elastis, turun presisi ke 1) di `graphShared.ts`, dipakai `nodeEntryProgress`
  (paritas SVG↔Canvas2D; test nodeEntry/edgeEntry diperbarui untuk semantik min
  opacity cap 1).

### ✅ A-2 · Icon Google (Material Symbols) ✓
Semua ikon memakai Material Symbols (`material-symbols-outlined.woff2`, terlihat di
network + DOM `dashboard`, `sticky_note_2`, `hub`, `search`, `settings`, …). Sesuai
parameter. Font Inter. Palet dark flat HSL konsisten (bg 12% gray, primary ungu
`hsl(252,60%,65%)`, accent cyan, semantic green/orange/red).

### ✅ A-3 · Empty/error states baik
- Editor: "Belum ada note terbuka — Pilih file di sidebar, atau buka cepat dengan pencarian."
- Chat: error provider jelas & actionable: *"Provider Google Gemini belum dikonfigurasi.
  Buka Settings → AI Providers, isi API key, lalu Save."* + tombol Copy / Retry / Append.
- Crash boundary: overlay dengan stack trace + tombol "Coba lagi" / "Reload".
- Composer placeholder informatif: "perintah / tanya kernel… (ketik / untuk perintah · Enter kirim · paste/drag gambar)".

### 🟡 A-4 · Kartu statistik dashboard boros ruang di viewport sempit
8 kartu stat (CATATAN…FILE) jatuh ke satu kolom vertikal penuh lebar di viewport
sempit (screenshot mock). Di lebar sudah grid. Responsif, tapi di jendela sempit
8 kartu full-width = banyak scroll untuk data kecil. Pertimbangkan grid 2 kolom
konsisten sejak dini atau compact chips.

### 🟡 A-5 · Search highlight memakai `«Alpha»`
Snippet hasil search menandai match dengan karakter `«…»` (bukan `<mark>`/background).
Secara visual mungkin OK, tapi pastikan bukan karakter literal yang menggantikan
highlight — prefer mark berwarna (konsisten dengan parameter "rapi").

### ✅ A-6 · Command palette & shortcut lengkap
Palette terstruktur: TAMPILAN / BUAT (Note baru Ctrl+N, Catatan harian Ctrl+Shift+D,
Note dari template Ctrl+Shift+N) / PANEL. Shortcut sidebar tercantum di label.

### 🟡 A-7 · Status bar info padat (mungkin terlalu padat)
Status bar menampilkan banyak segmen (vault · catatan · files/folders · graph · indeks).
Di jendela sempit berisiko terpotong/penuh — pastikan truncate & prioritas.
