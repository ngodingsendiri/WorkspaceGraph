## 1. Prinsip eksekusi

1. **Satu milestone = satu paket logis = satu commit** (atau beberapa commit kecil dalam milestone).
2. **Tiap milestone berakhir dengan gerbang wajib:** `npm run typecheck` + `npm test` hijau, item dicentang di `TODO_FIX`, status di-update.
3. **Ekstrak fungsi murni** untuk logika yang butuh unit test (konvensi repo yang sudah terbukti).
4. **Keputusan desain (Batch 4) diambil dulu** — beberapa item lain terblokir olehnya.
5. **Jangan memperluas scope.** Temuan baru selama perbaikan → catat ke TODO_FIX, bukan ikut dikerjakan.
